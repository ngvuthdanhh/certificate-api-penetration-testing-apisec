# ⚡ Lab – Rate Limiting & DoS

## Objective
Understand how missing rate limiting impacts API security.

## Steps
1. Use tools (e.g., `ffuf`, `ab`, `intruder`) to send high request volumes.  
2. Test endpoints like `/login` or `/reset-password`.  
3. Identify if brute-force attacks are possible.  

## Key Takeaways
- Implement rate limiting and lockout mechanisms.  
- Monitor logs for unusual request patterns.
