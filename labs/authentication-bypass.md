# 🔐 Lab – Authentication Bypass in APIs

## Objective
Practice identifying and exploiting weak or missing authentication in API endpoints.

## Steps
1. Intercept API requests with Burp Suite or Postman.  
2. Identify endpoints accessible without authentication.  
3. Attempt JWT manipulation or replay old tokens.  
4. Document successful unauthorized access.  

## Key Takeaways
- Always validate tokens server-side.  
- Rotate and expire tokens frequently.
