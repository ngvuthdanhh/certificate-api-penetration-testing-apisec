# 📘 API Penetration Testing – Overview

This repository contains **notes, labs, playbooks, and research** from the  
**API Penetration Testing (12 hours)** course by **ApiSec University**.  

The course focuses on:  
- Identifying and exploiting common API vulnerabilities  
- Understanding OWASP API Top 10  
- Hands-on API penetration testing labs  
- Secure coding practices & remediation techniques
