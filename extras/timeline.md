# ⏳ API Security Timeline

- **2017** – OWASP announces API Security Top 10 initiative  
- **2018** – Facebook token leak highlights API auth flaws  
- **2019** – OWASP API Security Top 10 v1 released  
- **2020** – API breaches account for 40% of all web app incidents  
- **2021** – Parler API misconfig incident  
- **2022** – Gartner predicts APIs will be the #1 attack vector  
- **2023** – OWASP API Top 10 draft update  
- **2025** – Modern pentesting labs emphasize API-first security testing
